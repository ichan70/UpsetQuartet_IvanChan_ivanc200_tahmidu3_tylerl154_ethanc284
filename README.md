## Overview
> "Scenario Σ: Your team has been contracted to create a collaborative storytelling game/website" - p0-RoH

In this application, you can read, view, create and edit stories to your own liking, but be warned: once you have edited a story for your first time, you are not allowed to make any changes. This sleek, minimalistic service provides plenty of top-quality stories for you to choose from, ranging from genres like Action & Adventure to Slice-of-life and Romance! Do not fret over details like constantly updating your program or having corrupted text: we have the rest covered.

### Installation guide

#### Prerequisites
Make sure that you have the following installed on your device:
* Python 3.13+ (Tested on Python 3.13.2)
  * The installation guide can be viewed [here](https://www.python.org/downloads/).
* Git (Tested on Git 2.54.0)
  * The installation guide can be found [here](https://git-scm.com/install/).

#### Setup
1. **Clone the repository**
  ```bash
   git clone https://github.com/ichan70/UpsetQuartet_IvanChan_ivanc200_tahmidu3_tylerl154_ethanc284.git
   cd UpsetQuartet_IvanChan_ivanc200_tahmidu3_tylerl154_ethanc284
   ```
2. **Create and activate a virtual environment**
  
  [View this chapter](#how-to-install-and-activate-a-virtual-environment)

3. **Install the dependencies**
  ```bash
   pip install -r requirements.txt
  ```
### Launch guide
4. **Run the application**
  ```bash
    python3 app/serve.py
  ```

5. **Go to the link provided**
  ```
  * Serving Flask app 'serve'
  * Debug mode: on
  WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
  * Running on http://127.0.0.1:5000
  Press CTRL+C to quit
  ```
  It may look something like this. Please visit the link provided (in this case, http://127.0.0.1:5000)
